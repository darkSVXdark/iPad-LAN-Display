# iPad LAN Display 0.3.0

На стороне Mac требуется macOS 14 или новее. Один файл приложения содержит сборки для Intel и Apple Silicon. На стороне планшета, телефона или компьютера откройте ссылку в браузере. Основной режим использует WebSocket и JPEG, резервный — HTTP JPEG. Совместимость зависит от браузера, а скорость от сети и устройства.

1. Распакуйте архив, перенесите приложение из папки `dist` в «Программы» и откройте его.
2. Нажмите «Доступ к экрану…», разрешите запись экрана и перезапустите приложение. Если macOS попросит доступ к локальной сети, подтвердите его для подключения браузера.
3. Выберите экран и локальный адрес, нажмите «Начать». Можно передать существующий экран или выбрать отдельный виртуальный экран, заранее созданный в BetterDisplay. Для передачи приложение запрашивает 1024×768 и требует источник не меньше 1024×768 физических пикселей.
4. Подключите устройство к той же сети, откройте показанную ссылку и один раз введите код. Затем открывайте тот же адрес в обычной вкладке Safari или другого браузера. Сохранённая пара привязана к данным браузера.
5. Окно можно закрыть. Управление остаётся в строке меню Mac.

В архиве локально подписанная сборка без нотариализации Apple. При блокировке запуска ознакомьтесь с [инструкцией Apple](https://support.apple.com/en-us/102445). Используйте доверенную локальную сеть, поскольку HTTP-передача экрана не шифруется.

Исходники включены. Для пересборки на Mac с Apple Command Line Tools запустите `./build.sh`. Если у вас есть сертификат подписи, укажите его через `IPAD_DISPLAY_SIGN_IDENTITY`. Для проверки протокола используйте `./test.sh`, для проверки логики браузера — `node Tests/client.cjs`.

Системный курсор macOS входит в изображение. Его обновление зависит от частоты кадров трансляции.
